Development

Contribute to GordonKit

Set up the GordonKit Document Converter development environment with uv, then format, lint, type-check, and test Python contributions before opening a pull request.

Local setup

The project uses uv for reproducible Python dependency management.

uv sync --dev --all-extras

Quality checks

Format, lint, type-check, and test before opening a pull request.

uv run ruff format --check .
uv run ruff check .
uv run mypy src
uv run pytest
