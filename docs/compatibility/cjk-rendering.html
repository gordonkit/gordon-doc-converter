Interpretation

The CI gate establishes that LibreOffice can open every package and produce a parseable, non-empty PDF. It does not assert pixel-identical rendering across LibreOffice versions, operating systems, Microsoft Word, or installed font sets. Word COM coverage remains on the controlled Windows runner because hosted runners do not include licensed Microsoft Office.

CI installs Noto CJK from the Linux distribution repository; the project does not download, bundle, or redistribute Microsoft fonts. When pagination or glyph appearance matters, record the renderer version and installed font set with the test result.
