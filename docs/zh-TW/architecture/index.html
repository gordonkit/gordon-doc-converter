開發指南

文件轉換器系統架構

了解 GordonKit 可攜式文件轉換架構，包括 application service、引擎協定、政策協調、adapter 與 PDF 驗證。

相依流向

函式庫與 CLI 呼叫皆進入 application service，由 orchestrator 套用政策後，再呼叫共用 engine protocol 並驗證產出的 PDF。

Library / CLI
  -> Application service
  -> Orchestrator and policy
  -> Engine protocol
  -> PDF validation

Adapter 規則

平台 API 與 subprocess 限制在引擎 adapter 內。Windows 專用相依套件採延遲匯入，確保核心套件維持跨平台。
