開發指南

參與 GordonKit 開發

使用 uv 設定 GordonKit 文件轉換器開發環境，並在提出 Pull Request 前完成 Python 格式化、lint、型別檢查與測試。

本機設定

專案使用 uv 管理可重現的 Python 相依套件。

uv sync --dev --all-extras

品質檢查

提出 Pull Request 前，請完成格式化、lint、型別檢查與測試。

uv run ruff format --check .
uv run ruff check .
uv run mypy src
uv run pytest
