Document conversion deployment modes

Choose Word COM, LibreOffice, or Gotenberg conversion policies for interactive Windows desktops, servers, and containers without silent engine fallback.

Desktop

Interactive Windows desktops may automatically select Word COM when licensed Word is available. This applies to both DOCX-to-PDF and DOCX-to-HTML conversion; HTML output through Word COM produces higher visual fidelity than semantic extraction.

Server and container

Server mode prefers Gotenberg then LibreOffice. The container includes LibreOffice and can use an external Gotenberg service; it never auto-selects Word COM.

Rendering may differ between Word and LibreOffice. Test representative documents before rollout.
