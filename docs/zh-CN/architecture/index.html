开发指南

文档转换器系统架构

了解 GordonKit 可移植文档转换架构，包括 application service、引擎协议、策略协调、adapter 与 PDF 验证。

依赖流向

库与 CLI 调用皆进入 application service，由 orchestrator 应用策略后，再调用共用 engine protocol 并验证产出的 PDF。

Library / CLI
  -> Application service
  -> Orchestrator and policy
  -> Engine protocol
  -> PDF validation

Adapter 规则

平台 API 与 subprocess 限制在引擎 adapter 内。Windows 专用依赖包采延迟导入，确保核心包维持跨平台。
