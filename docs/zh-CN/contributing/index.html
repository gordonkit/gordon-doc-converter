开发指南

参与 GordonKit 开发

使用 uv 设置 GordonKit 文档转换器开发环境，并在提出 Pull Request 前完成 Python 格式化、lint、类型检查与测试。

本地设置

项目使用 uv 管理可重现的 Python 依赖包。

uv sync --dev --all-extras

质量检查

提出 Pull Request 前，请完成格式化、lint、类型检查与测试。

uv run ruff format --check .
uv run ruff check .
uv run mypy src
uv run pytest
