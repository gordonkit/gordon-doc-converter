运维部署

文档转换部署模式

为交互式 Windows 桌面、服务器与容器选择 Word COM、LibreOffice 或 Gotenberg 文档转换策略，且不会静默切换引擎。

桌面模式

交互式 Windows 桌面在具备合法授权 Word 时，可自动选用 Word COM。此规则同时适用于 DOCX 转 PDF 与 DOCX 转 HTML；通过 Word COM 输出的 HTML 比语义提取具有更高的视觉忠实度。

服务器与容器

服务器模式依序偏好 Gotenberg、LibreOffice。容器内含 LibreOffice，也可使用外部 Gotenberg service，且绝不自动选用 Word COM。

Word 与 LibreOffice 的排版可能不同，生产上线前应以代表性文档测试。
