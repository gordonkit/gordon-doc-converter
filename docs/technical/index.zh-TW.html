架構產物路由引擎政策安全控制進階操作私有 API

IMPLEMENTATION REFERENCE / v0.4

受政策控制、限制外部工作量的文件轉換服務。

GordonKit 協調文件引擎與 artifact 處理元件；它不實作 Word 排版引擎，也不承諾跨引擎與字型環境的像素完全一致。

01

架構與邊界

不依賴 framework 的 application service 負責 request、result、引擎選擇、fallback、驗證與發布。CLI 與 FastAPI 是呈現 adapter；引擎 adapter 只負責 probe 與執行自身 renderer。

Service

單次、批次與 probe 的穩定公開入口。

Pipeline

組合路由、記錄 warning、驗證與發布 artifacts。

Adapters

封裝 Word COM、LibreOffice 與選用 Gotenberg 細節。

02

產物路由

來源目標處理路徑
DOCXPDF依政策選擇 renderer、驗證 PDF、原子式發布。
DOCXMarkdown / HTML直接語意擷取並以具決定性的 writer 輸出。
PDFMarkdown / HTML擷取內嵌內容；純圖片內容會回報需要 OCR。
DOCX 或 PDF頁面圖片先驗證 PDF，再使用已安裝的 PDFium/Pillow rasterizer。

同時要求 PDF 與頁面圖片的 DOCX 只會暫存並驗證一次 PDF；Markdown 與 HTML 共用一次 normalized content 擷取。

03

引擎選擇與 fallback

執行前 probe 會確認可用性及 revisions/comments 能力。明確引擎與 strict mode 不會 fallback；自動模式只能改用另一個具備能力的引擎，並記錄 ENGINE_FALLBACK warning 與原因。

互動式 Windows desktop

Word COM、LibreOffice、Gotenberg。

其他 desktop 環境

LibreOffice、Gotenberg。

Server

Gotenberg、LibreOffice；排除 Word COM。

Container

設定的 container engine、另一個替代引擎；Word COM 無效。

04

安全控制

不可信輸入驗證

  • 副檔名與選用 MIME type 必須符合格式。
  • 預設來源上限 50 MiB，PDF 至多 1,000 頁。
  • DOCX 會拒絕加密、危險 ZIP 路徑、過多 entries、過度解壓、可疑壓縮比與缺少核心 OOXML parts。

外部程序安全

  • 以參數序列執行，固定 shell=False。
  • 擷取 UTF-8 replacement 輸出，且每個程序都有 timeout。
  • 逾時會終止 process tree；引擎工作使用隔離的 temporary directory。

操作規則：不得記錄文件內容、憑證、客戶 metadata、敏感完整路徑或原始 adapter traceback。

05

進階操作

發布語意

引擎輸出會先 staging，再檢查存在、非空、可解析與正頁數。除非指定 overwrite，發布時以 exclusive create 保護目標；overwrite 會使用同一目錄的暫存檔及 replace。

Container 與遠端 renderer

使用 repository 明確的 Compose profiles 啟動 LibreOffice standalone API、Gotenberg gateway 或 CLI image。CLI 以 --gotenberg-url 設定 Gotenberg；API 使用 GORDON_DOC_GOTENBERG_URL。

CJK 重現性

結果應記錄 renderer version 與 installed font set。compatibility fixtures 證明 LibreOffice 可產生可解析 PDF，不代表跨系統、renderer 或字型 inventory 的像素完全一致。

06

私有 API 部署

選用 FastAPI adapter 用於私有部署；它從 /conversions 接收 DOCX bytes、回傳 PDF，且不允許 Word COM。預設 service 會以非互動 Linux container policy 運作。

控制項行為
驗證選用 Bearer token 以 constant-time comparison 檢查；應設定強度足夠的 GORDON_DOC_API_KEY。
資源限制process-local fixed-window rate limit 與 bounded concurrency 用盡時回傳 429。
Hooksauthentication、malware scan 及不含內容的 telemetry 可注入。
生命週期輸入與輸出都在 temporary directory staging，request 結束後移除。

多 replica 部署時，請在 ingress 層實施 request body limit 與 distributed rate limiting。啟動與 smoke test 指令請見 container profile reference。
