開発

GordonKit へのコントリビュート

uv で GordonKit ドキュメントコンバーターの開発環境を構築し、Pull Request を出す前に Python の書式整形、lint、型チェック、テストを実行します。

ローカル環境の構築

本プロジェクトは再現性のある Python 依存管理のために uv を使います。

uv sync --dev --all-extras

品質チェック

Pull Request を出す前に、書式整形、lint、型チェック、テストを実行してください。

uv run ruff format --check .
uv run ruff check .
uv run mypy src
uv run pytest
