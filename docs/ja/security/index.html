プロジェクト

安全なドキュメント変換

拡張子、MIME、OOXML、ファイルサイズ、解凍の検証、分離した実行、非公開の脆弱性報告により、信頼できないドキュメントの変換を安全に行います。

入力の扱い

拡張子、MIME type、OOXML 構造を検証します。信頼できないドキュメントを処理する前に、サイズと解凍の制限を適用してください。

脆弱性の報告

SECURITY.md に記載された非公開の報告手順に従ってください。公開 issue に機微なドキュメントのサンプルを載せないでください。
